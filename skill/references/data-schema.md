# Data schema

Nodes use `id`, `pid`, `name`, `tree`, `url`, and `institution`. Edges use `source_id`, `target_id`, `relation`, `source_url`, and `confidence`. Works use `work_id`, `title`, `authors`, `author_ids`, `publication_year`, `publication_date`, `doi`, `venue`, `institutions`, `topics`, `cited_by_count`, `referenced_works`, `open_access`, `sources`, and `match_confidence`.
